  设计要点

  - 实例 = 外设驱动：CANInstance 收敛多订阅者链表（经典+FD 各 8 槽）、双环形发送队列、tx_lock/tx_pend 服务锁（__disable_irq 临界区 C 化 atomic）、fifo、mode/fd_mode 缓存。
  - 旧式兼容保留：rx_id_list/rx_mask/rx_frame_type/rx_callback、CANTransmit 路径原样保留；无订阅者的实例走旧式 ID 匹配，有订阅者的走订阅分发，二者共存。
  - 错误帧：错误事件构造 type=CAN_FRAME_ERROR + 虚拟 ID 走经典订阅通道（对应 xrobot ERROR 语义）。
  - 修复了一处 FD 帧进旧式路径时 rx_pack.data[8] 越界拷贝的隐患。
