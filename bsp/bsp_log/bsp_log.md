# bsp_log特点

### 功能

1. 日志类型分级
2. 分级不同颜色
3. 可选时间戳
4. 支持分模块限制发送速度
5. 发送次数计数
6. bsp/bsp_log/bsp_log.h有一个log的日志对象直接可用
7. 支持中文UTF-8

### 性能

1. 手写快速格式化，反汇编验证除余和整除使用魔数加速
2. 日志和调用的格式化可重入，格式化到一半被中断打断依然可以发送另一个日志
3. bsp/bsp_log/bsp_log.c定义静态内存s_log_buf，反汇编查看路径从flash直接到bsp/bsp_log/bsp_log.c的静态内存区，栈空间使用少，被多次重入栈空间不足可能性小
4. dma异步发送
