# 电机及axis，chassis驱动文档

## 设计思路和原因

| 设计思路                                                         | 原因                                                                                                                 |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 中断只拷贝数据，getdata再解析                                    | 1.中断尽量可能少计算。2.不能像sbus那样，电机有的时候需要里程计，需要数据的精确时间戳。                               |
| 使用MotorBase_s基类统一MotorData_s数据类型                       | 相当于硬性规范，每种电机驱动都要这么写                                                                               |
| 电机驱动所有数据和减速箱无关，是纯电机数据                       | 3508可以更换不同减速箱，减速相关放到axis或者chassis驱动里面                                                          |
| 电流还是力矩                                                     | setref和getdata统一单位力矩。dji私有一个*转矩常数*手动设置，让标定的量有物理意义，也可以给1                          |
| 函数表接口                                                       | 基类使用统一函数表，axis和chassis初始化电机时候需要填入MotorVTableSimple_s的函数指针，不传入实例每个电机用单独的函数 |
| axis，chassis驱动                                                | 集成**减速比**字段，放大力矩/电流，减小位置，速度，加速度。                                                          |
| MotorVTableSimple_s 没有set_offset                               | 初始化时手动归零                                                                                                     |
| 外部反馈需要自己把数据处理好，例如归一化等，驱动内部不做任何处理 | 内部处理实现复杂，影响getdata的语义                                                                                  |
| motor_direction和feedback_direction                              | motor_direction在计算电流时乘，feedback_direction在解析数据时乘（位置，速度，电流？）                                |
| 归一化到任何范围                                                 | 电机驱动没有集成加速比                                                                                               |
| 多圈，偏置，归一化，方向4个计算的顺序                            | 累加-偏置-方向-归一化                                                                                                |
| 归一化只要一个范围，但是基类有上下限                             | 兼容限幅模式                                                                                                         |

## 数据处理流程

```text
callback → getadata
              ↓
refer → calculate → send
```

### callback

拷贝数据到双缓冲区中，标记翻转，缓存失效。（问题：在getdata的拷贝过程中连续2次can中断，几乎不可能）

### getadata

##### speed

1. 电机/外部反馈（外部反馈必须是rad/s）
2. 是否滤波

###### position_single

电机/外部反馈（外部反馈必须是rad，不进行限幅，归一化，偏置）

###### position

1. 累加（速度修正，速度修正）
2. 偏置
3. 限幅/归一化/无处理3种模式：
   1. 限幅模式：获取的数据不处理
   2. 归一化模式：归一化到设定范围
   3. 无处理：无处理

dji，dm电机多圈语义需要保持一致，都归一化到指定范围

### refer

1. 限幅/归一化/无处理3种模式下设定值处理：
   1. 限幅模式：限幅到指定范围
   2. 归一化模式：归一化到指定范围，之后误差也一定要归一化
   3. 无处理：不处理

误差归一化
