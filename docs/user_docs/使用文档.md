msys2安装方法：

**`git`,`cmake`,`ninja`,`openocd`使用`msys2`安装方法**  
在`mingw64.exe`运行以下命令

- 先更新`MSYS2`本身
  ```bash
  pacman -Syu
  ```
- 安装`git`
  ```bash
  pacman -S git
  ```
- 安装`cmake`
  ```bash
  pacman -S mingw-w64-x86_64-cmake
  ```
- 安装`ninja`
  ```bash
  pacman -S mingw-w64-x86_64-ninja
  ```
- 安装`openocd`
  ```bash
  pacman -S mingw-w64-x86_64-openocd
  ```

# 框架使用方法

### 编译默认项目

1. `cmd`运行`git clone git@github.com:itgz123/BetaRobot.git my_project`克隆主仓库，再运行`bash scripts/setup_apps.sh`拉取独立 app 仓库
2. 复制`user_cfg.h.example`为`user_cfg.h`
3. `vscode`中按`Ctrl`+`Shift`+`B`编译默认项目

### 开发自己的`app`

app 是**独立 git 仓库**，主仓库不追踪、不绑定。开发新 app 的流程：

1. 新建独立仓库（例如 `BetaRobot-App-MyApp`），编写 `CMakeLists.txt`（参考 `app/half_rudder_gimbal/CMakeLists.txt`：定义 `MODULE_SOURCES` 和 `MODULE_INCLUDE_DIRS`，路径相对 app 目录）
2. 在 `app/` 下 clone 或放置该仓库：`git clone <你的仓库URL> app/my_app`
3. 在 `user_cfg.h` 中设置 `#define APP_NAME my_app`
4. 若想让主仓库忽略该目录（推荐，保持独立），在 `.gitignore` 增加 `/app/my_app/`

主仓库编译时通过 `app/<APP_NAME>/CMakeLists.txt` 引入该 app，路径规则见顶层 `CMakeLists.txt`。
