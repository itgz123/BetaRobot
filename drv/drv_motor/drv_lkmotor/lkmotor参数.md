# LK（瓴控/翎控）MF 电机参数

> 来源：《电机 CAN 总线通讯协议 V2.36（一对一）》与《产品手册（瓴控）》选型表。
> 首版驱动仅支持 MF 系列（一对一 CAN 协议，标准帧，CAN_ID = 0x140 + 电机ID，默认 1Mbps）。

## 一、协议固定量纲（不随型号变化）

| 项          | 线值         | 换算                     | 备注                                                  |
| ----------- | ------------ | ------------------------ | ----------------------------------------------------- |
| 转矩电流 iq | int16，±2048 | `A = raw × 33/4096`      | MF 满量程 ±16.5A（对应 iq 原始 ±2048）；MG 为 66/4096 |
| 转速        | int16        | `rad/s = raw × π/180`    | 1 dps/LSB                                             |
| 编码器      | uint16       | `rad = raw × 2π / 65536` | 实测整圈 raw 0~65535，转一圈恰好回绕一次（按 16bit）  |
| 温度        | int8         | `℃ = raw`                | 1℃/LSB                                                |

## 二、MF 全系列 Config 参数表

Config 中**随型号/绕线变体变化的只有 `torque_constant`（Kt）**；
iq 分辨率/幅值上限与编码器量纲对全系列 MF 一致，已是**驱动内常量**，不暴露 Config。

**全系列 MF 固定项（驱动内常量）：**

## 三、Config 填写位置

两个驱动（`drv_lkmotor` 一对一 / `drv_lkmotor_broadcast` 一拖四，实机在用后者）的 Config 都只有以下项需填：

| 参数                 | 是否随型号变 | 说明                                            |
| -------------------- | ------------ | ----------------------------------------------- |
| `torque_constant`    | ✅ 是        | 填上表 Kt（当前硬件 MF7015-23T = 0.28）         |
| `motor_id` / `can_e` | 安装决定     | 一对一：CAN_ID = 0x140 + motor_id；广播：ID 1~4 |

> 注：两个驱动的接口已对齐（2026-09-12）——`LKMotor_Config_s` / `LKMotorBroadcast_Config_s`
> 都只暴露 `torque_constant` 一个量纲参数，iq 分辨率、iq 幅值上限、编码器量纲全部为驱动内常量。
> `LKMotor_SendModeCmd`（0x80/0x88/0x9C）是一对一独有的模式命令，广播驱动无对应接口。
