# 超级电容 CAN 对接接口

本文用于主控、运动控制及其他 AI 对接；仅支持新格式。总线为 **经典 CAN、1 Mbit/s、11 位标准 ID、数据帧、DLC=8**；多字节整数按小端序发送，D0～D7 为数据区第0～7字节。

| 方向        |  CAN ID | 数据结构    | 说明                       |
| ----------- | ------: | ----------- | -------------------------- |
| 主控 → 超电 | `0x061` | `RxData`    | 建议每10 ms发送完整命令    |
| 超电 → 主控 | `0x052` | `TxDataNew` | 当前固件每1 ms尝试发送一帧 |

只处理上述格式的 `0x061` 命令；不再发送旧浮点反馈或根据命令切换格式。

## 主控 → 超电：`0x061`

```cpp
#include <stdint.h> // 固定宽度整数类型。
struct RxData { // 8字节命令，按D0到D7发送。
    uint8_t enableDCDC : 1; // D0 bit0：1允许启动DCDC，0撤销启动许可并关闭输出。
    uint8_t systemRestart : 1; // D0 bit1：1关闭功率级并重启MCU，通常发送0。
    uint8_t resv0 : 3; // D0 bit4:2：保留位，发送0。
    uint8_t clearError : 1; // D0 bit5：1清除可清除故障，触发后恢复0。
    uint8_t enableActiveChargingLimit : 1; // D0 bit6：1启用D5主动充电目标，0允许充至最高电压。
    uint8_t resv1 : 1; // D0 bit7：保留位，发送0；超电接收时忽略。
    uint16_t refereePowerLimit; // D1~D2：裁判/上游功率预算，单位W，小端。
    uint16_t refereeEnergyBuffer; // D3~D4：能量缓冲，单位J，小端。
    uint8_t activeChargingLimitRatio; // D5：主动充电目标比例，范围0~255。
    int16_t resv2; // D6~D7：保留字段，发送0。
} __attribute__((packed)); // 禁止编译器插入填充，sizeof必须为8。
```

主动充电目标电压为 `clamp(sqrt(ratio / 255.0) × 28.8, 10.0, 28.8) V`，仅bit6=1时生效；D5=0对应10 V，停机请用bit0=0。允许充至最高电压时不限制主动充电目标，能量回收仍受保护约束。

`refereeEnergyBuffer` 参与以 **57 J** 为目标的缓冲能量环，功率修正限幅±15 W；最终输入功率目标限制为 **5～135 W**。无裁判系统的平台需约定字段来源；发送57 J表示缓冲达到目标，不能直接把分支功率当作电池总功率。

## 超电 → 主控：`0x052`

```cpp
struct TxDataNew { // 8字节唯一反馈，固定使用CAN ID 0x052。
    uint8_t statusCode; // D0：状态位，bit6固定为1表示本协议。
    uint16_t chassisPower; // D1~D2：负载功率raw，小端；功率W=raw/64.0-256.0。
    uint16_t refereePower; // D3~D4：上游输入功率raw，小端；编码同上，非主控预算回显。
    uint16_t chassisPowerLimit; // D5~D6：当前可用功率估算，单位W，小端。
    uint8_t capEnergy; // D7：电容能量估算，正常满电值为250。
} __attribute__((packed)); // 禁止填充，sizeof必须为8。
```

功率编码为 `raw = clamp(P_W × 64 + 16384, 0, 65535)` 后截断取整；解码必须使用浮点除法。范围 **−256～767.984375 W**，分辨率0.015625 W，越界饱和值不代表真实峰值。负功率表示回流。

测量来源：`refereePower` 为低通后的 `vA × iR`；`chassisPower` 为低通后的 `vA × (iR − iA)`，E桥工作时再减去无线充电功率。`chassisPowerLimit = CAPARR::getMaxPowerFeedback() + refereePowerLimit`，是可用功率估算，不能直接当作BMS额定值。

`capEnergy ≈ (Vcap / 28.8)^2 × 250`，125=50%，250=100%，超过250表示估算超过额定满电；命令D5的比例分母则为255。

### `statusCode` 位定义

| 位     | 含义         | 值                                                                   |
| ------ | ------------ | -------------------------------------------------------------------- |
| bit7   | DCDC实际输出 | `1` 已启动；`0` 未启动或被保护关闭                                   |
| bit6   | 协议版本     | 固定为 `1`                                                           |
| bit5:4 | 无线充电状态 | `0` 异常/无硬件，`1` 关闭，`2` 充电，`3` 完成                        |
| bit3:2 | 当前限制因素 | `0` 上游功率，`1` 最高电容电压，`2` 主动充电目标，`3` 电容充放电限流 |
| bit1:0 | 故障等级     | `0` 无/警告，`1` 自动恢复，`2` 手动清除，`3` 不可清除                |

故障等级=`statusCode & 0x03`，不包含具体故障原因，且不能区分正常与警告。清错命令可处理等级1/2，建议人工对等级2触发一次；它可能恢复输出，应在允许恢复运行时使用。

## 打包示例

| 示例     | ID      | D0→D7十六进制             | 含义                                                                        |
| -------- | ------- | ------------------------- | --------------------------------------------------------------------------- |
| 运行命令 | `0x061` | `01 50 00 39 00 FF 00 00` | 允许DCDC；预算80 W、缓冲57 J；主动充电限制关闭                              |
| 停机命令 | `0x061` | `00 50 00 39 00 FF 00 00` | 撤销DCDC许可，其余同上                                                      |
| 状态反馈 | `0x052` | `D0 00 59 00 54 F4 01 7D` | DCDC已启动、无线关闭、上游功率限制；负载100 W、输入80 W、可用500 W、电量50% |

**超过500 ms未收到有效命令**：回退为37 W输入目标，取消主动充电限制，**不会因失联强制关闭DCDC**；停机期间应持续发送bit0=0。bit0=1仅代表许可，须以反馈bit7确认实际启动。

跨平台实现应按上述 D0～D7 的字节偏移和位掩码打包，不依赖 C/C++ 位域的编译器布局；接收多字节字段时按小端序读取。
