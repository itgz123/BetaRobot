## 分层架构

**当前主要用stm32，所以bsp和hal写得不是很好**

### bsp

把stm32或其他芯片封装为统一接口。之后得改为每种芯片一个文件。

### hal

直接调用stm32hal库或ll库解初始化/初始化，修改一些配置

### drv

实现常见其他传感器，电机，遥控等的协议

### lib

提供一些独立的计算库，不依赖于bsp等

### drvlib

联合drv和lib，让rm情况下更方便

### app

每个人自己写的应用代码

##### 1. axis

1. 反馈：pid/mit
2. 前馈：摩擦，重力，惯量（离心力，科里奥利力）
3. 命名：

```
axis_[pid/mit]_[lite/无]
```

##### 2. gimbal

综合axis，使用dh_matrix简化运动学计算

##### 3. shoot

1. 功能：热量计算，射速，射频，子弹数量剩余，异常处理（退弹等）

##### 4. chassis

1. 功能：运动学正逆解，功率控制有无，类型，位控/力控，里程计
